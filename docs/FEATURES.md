## 2. 设计原则

1. **短信优先**：收件箱只放会话；验证码单独成页，不挤占主界面。
2. **本地优先**：解析、搜索、回收站、密钥都在设备上；联网仅用于用户主动配置的同步。
3. **形状即反馈**：未读、选中、发送状态通过形状、颜色与动效表达，而不是堆叠图标。
4. **连续感**：页面切换、列表进入、气泡出现共享同一套时间与弹簧参数；没有硬切。
5. **可恢复**：删除先进入回收站；永久删除必须二次确认。
6. **诚实的能力边界**：文档只写已实现/进行中的部分，并列出限制。

## 3. 交互细节

- **收件箱**：大标题 + 日期眉题；搜索胶囊聚焦时描边与柔光增强；筛选条选中项
  以渐变胶囊形变；会话卡未读时头像形变为 `sunny`，卡片出现极光渐变。
- **滑动**：右滑置顶、左滑归档；动作完成后行不消失，等待数据刷新，避免"闪回"。
- **会话**：相邻同向消息收拢圆角；日期分隔；长按进入多选，顶部工具栏切换；
  失败消息提供"重新发送"；链接与验证码行内高亮。
- **撰写**：分段计数实时计算；附件/定时/SIM 收在输入框上方；发送键
  在空/有内容之间 `circle ↔ cookie9` 形变；发送后列表回到底部。
- **验证码页**：大号等宽数字、一键复制、来源与时间、隐私提示。
- **回收站**：保留策略胶囊；恢复/永久删除；永久删除前对话框。
- **外观**：实时预览气泡与色板；动效档位（全速/平衡/省电）；字体缩放。
- **同步**：设备指纹可复制；配对码/服务器地址；设备列表与手动同步。

## 4. 与 CapsuleSMS 的关键差异

| 维度 | CapsuleSMS | 青鸟短信 |
|---|---|---|
| UI 技术 | 原生 View / Java | Flutter，自绘极光背景与形状 |
| 核心逻辑 | Java | Rust（分析/索引/分段/PDU/加密） |
| 设计语言 | ColorOS 圆角卡片 | Material 3 Expressive + 超椭圆 |
| 动效 | 属性动画 | 统一 Ticker + 弹簧 + 共享轴 + 形变 |
| 渲染优化 | 无集中调度 | 帧耗时自适应、滚动退避、背景隔离 |
| 验证码 | 列表内高亮 | 独立验证码中心 + 形变复制反馈 |
| 同步 | 自建 Node 服务 | Rust 客户端 + Rust 最小服务端 |

## 5. 已知限制

- 当前 Android 平台层仍在与协作分支合并；部分方法（通知直回、定时发送、
  MMS 下载、备份导入）需要设备验证。
- MMS PDU 只实现 M-Retrieve.conf 子集；GB2312 文本离线解码为尽力而为。
- 搜索索引在内存中重建；超大短信库（>5 万条）只索引前 4k 字符/条。
- 未实现：富媒体预览编辑、RCS、双卡通话、垃圾短信云端模型。
